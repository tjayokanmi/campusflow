# CampusFlow

CampusFlow is a command-line helpdesk ticket management system built with Python. It helps campus staff create, prioritize, assign, and track technical support requests.

## Features

* Create and manage support tickets.
* Automatically calculate ticket priorities.
* Assign tickets to staff members.
* Track ticket status from open to resolved.
* View an ordered work queue and ticket reports.
* Save and load tickets using JSON.
* Run automated tests with `unittest`.

## Technologies

* Python 3.11+
* JSON
* Git and GitHub
* Python `unittest`

## Getting Started

Clone the repository:

```bash
git clone <repository-url>
cd campusflow-ruby
```

Run the application:

```bash
python main.py
```

Run the tests:

```bash
python -m unittest discover -s tests -v
```
